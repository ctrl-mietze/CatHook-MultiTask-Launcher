# Legacy / Easy Mode

Legacy / Easy Mode is an optional compatibility UI for people who want the old app-first workflow without bringing the old backend back.

## Enable

Open **Settings → Developer Options → Legacy / Easy Mode**.

## What changes

- Apps return directly to a simplified Home screen.
- The UI remains the modern CatCore design.
- **Start as app's own task** is enforced.
- The current V2 own-task backend is still used.
- CatCore Framework remains available as the lightweight framework/session backend.
- Advanced V2 controls are intentionally hidden from the simplified flow.

Turning Easy Mode off restores the full V2 interface.

This mode is a UI/feature reduction, not a downgrade to the old V1 implementation.
